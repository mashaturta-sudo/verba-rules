# Verba Rules — Android

Мобільний довідник правил Verba Online.

## Що є у версії 1.0
- Пошук за номером, текстом і ключовими словами.
- Фільтр за 8 розділами.
- Фільтр правил із покаранням.
- Детальна картка правила: текст, покарання, примітки/винятки, приклади.
- «Розбір ситуації» з локальним підбором найбільш схожих правил.
- Працює офлайн після встановлення.

## Збірка APK
В Android Studio відкрий цю папку як Gradle-проєкт і виконай:
`Build -> Build APK(s)`.

Або завантаж проєкт у GitHub: workflow `.github/workflows/build-apk.yml` автоматично збере debug APK.
